# Link descriptions

Link results identify the hostname, a likely category, and a known organization
when an exact domain or a subdomain matches the small reference list. This is
local address inspection. It does not fetch the page, follow redirects, verify
ownership, certify legitimacy, or change the risk score. Unknown government
domains get a category but no invented agency name. Embedded redirect parameters
are shown as possible onward destinations; shortened links remain unresolved.

Named government references checked on 24 November 2026:

- [GOV.PH National Government Portal](https://ngp.e.gov.ph/the-govph)
- [Bureau of Internal Revenue](https://www.bir.gov.ph/home)
- [Social Security System](https://www.sss.gov.ph/)

Bank, wallet, shopping, and social names reuse the domains already listed in
Surfare's URL rules and platform references. These names are descriptive hints,
not reputation findings. Literal hostnames are displayed as text, without links
that might encourage a user to visit a suspicious destination.
