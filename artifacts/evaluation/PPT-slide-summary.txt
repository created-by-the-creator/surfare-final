Slide: How Surfare was trained
Surfare is a hybrid of trained compact classifiers, contextual rules, exact reference matching, OCR/QR extraction, and optional external AI.
Imported SMS model: UCI SMS Spam Collection + Filipino Spam SMS.
Current text model: A.S.E.A; legitimate samples from Filipino original/merged, SMS Spam Collection and Hinglish; IMC25 scam samples; authored augmentation.
URL model: PhiUSIIL raw URLs. dataset_phishing.csv is not used to train the runtime models.
Dataset text/URL models are advisory; rule/reference evidence determines risk alongside the SMS signal.
URL training reproduces exactly; current text preprocessing does not reproduce the saved text model. No runtime models changed.
